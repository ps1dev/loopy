    This page has to be served over HTTP

    Opening index.html directly gives it a file:// address, and browsers refuse to load ES modules from there. The page draws, and then nothing works, which is why you are seeing this instead of silence.

    In a terminal, from the folder holding index.html:

    python3 -m http.server 8080

    then open http://localhost:8080/.

    On macOS you can double-click serve.command in this folder instead, which does both.
